# BO2-Requiem-NX
Requiem Project: A port of the Ghidra decompilation of Black Ops II's PC executables) to Horizon, built with devkitPro and libnx. The engine runs as AArch64 code with 32-bit pointers (ILP32) inside a normal 64-bit libnx NRO;  The game renders into the native Deko3D renderer for Switch and uses Drako3D for the Switch 2 build.

Currently limited to Zombies and Multiplayer. Campaign needs to be fully decompiled to be included here.

Goal of the project is to have crossplay online servers with most devices
